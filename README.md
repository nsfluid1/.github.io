# NSFluid

NSFluid is a modern news platform built with Next.js 14 (App Router), TypeScript, Tailwind CSS, shadcn/ui, Prisma, and PostgreSQL. It features passwordless authentication with NextAuth, storage via Supabase, full-text search powered by Meilisearch, and extensive security and accessibility defaults.

## Development

```bash
npm install
npm run dev
```

## Testing

```bash
npm test
npm run test:e2e
```

## Environment Variables

See `.env.example` for all configuration including database, authentication, storage, and search providers.
